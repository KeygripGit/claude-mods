# Keygrip Claude Code mods

A Claude Code plugin marketplace. The same mods are served by the app at
https://app.keygrip.ai/mods/marketplace.json (the setup guide is https://app.keygrip.ai/mods/);
this repository exists so the desktop app's plugin browser, which lists git-hosted marketplaces,
can show them too.

```
claude plugin marketplace add KeygripGit/claude-mods
claude plugin install workorder-pane@keygrip
```

Then type `/workorders` and paste your project's client key into the pane when it asks.
